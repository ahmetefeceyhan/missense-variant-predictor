# CFTR — Tuned Model Search (XGBoost / LightGBM / CatBoost / NN / DNN)

This folder takes the CFTR panel's **best feature set** and grid-searches **five model
families** to see which predicts `Label` (0 = benign, 1 = pathogenic) best — a step up from the
earlier "nothing fancy" single-XGBoost baseline.

| File | What it is |
|------|------------|
| `CFTR_search_models_results.csv` | One row per model family, **sorted best test F1 → worst**. |
| `CFTR_search_models.png` | Bar chart of test F1 by model family. |
| `README.md` | This document. |

Generated by `feature_depth/second_part_for_in_depth_search_models.py --panel CFTR`.

---

## ⚠️ Very small panel

CFTR has 111 variants (90 pathogenic / 21 benign). The 80/20 holdout leaves a **23-row test
fold with only 4 benign rows**, so one misclassified sample shifts F1 by ~0.04–0.05. All
numbers here are noisy — read them as rough and relative. The majority-class floor
(always-predict-pathogenic) is **F1 ≈ 0.905** on this test fold.

## Setup

- **Feature set:** literal report best — **3 features** `[AL_6, AL_215, AL_21]` (the tied-best
  single features from the earlier analysis).
- **Preprocessing:** `raw` values + **median** impute; categoricals ordinal-encoded. NN/DNN
  additionally get `StandardScaler`.
- **Five model families:**
  - **XGBoost** — grid: `max_depth∈{3,5}`, `learning_rate∈{0.05,0.1}`, `n_estimators=200`, `scale_pos_weight∈{1, neg/pos}`.
  - **LightGBM** — `num_leaves∈{15,31}`, `learning_rate∈{0.05,0.1}`, `n_estimators=200`, `scale_pos_weight∈{1, neg/pos}`.
  - **CatBoost** — `depth∈{4,6}`, `learning_rate∈{0.05,0.1}`, `iterations=200`, `auto_class_weights∈{default, Balanced}`.
  - **NN** (shallow MLP) — `hidden_layer_sizes∈{(32,),(64,)}`, `alpha∈{1e-4,1e-3}`.
  - **DNN** (deep MLP) — `hidden_layer_sizes∈{(64,32),(128,64,32)}`, `alpha∈{1e-4,1e-3}`.
  - *Note:* `MLPClassifier` has no class-weight option, so NN/DNN run unweighted (the imbalance
    axis applies only to the three tree libraries).
- **Evaluation:** grid search via **3-fold StratifiedKFold on the train split only** (CFTR has
  ~17 benign train rows), scoring F1; the refit best estimator is scored on the held-out test
  fold. Train = 88 (17 benign / 71 path), test = 23 (4 benign / 19 path). Seed 42 throughout.

## Results (test fold, sorted best F1 → worst)

| model | cv F1 | test F1 | test acc | test recall | test precision | best params |
|-------|------:|--------:|---------:|------------:|---------------:|-------------|
| **XGBoost** | 0.882 | **0.950** | 0.913 | 1.000 | 0.905 | depth 3, lr 0.05, spw 1 |
| LightGBM | 0.893 | 0.905 | 0.826 | 1.000 | 0.826 | leaves 15, lr 0.05, spw 1 |
| CatBoost | 0.895 | 0.900 | 0.826 | 0.947 | 0.857 | depth 4, lr 0.05 |
| NN | 0.897 | 0.872 | 0.783 | 0.895 | 0.850 | (64,), α 1e-4 |
| DNN | 0.895 | 0.872 | 0.783 | 0.895 | 0.850 | (64,32), α 1e-4 |

## What we found

- **XGBoost wins (test F1 0.950)** and matches the best single-feature result from the earlier
  analysis — but that is only **one benign sample above the floor (0.905)**, so it is not a
  meaningful separation, just the best of a noisy bunch.
- **The neural nets are weakest** (0.872). With 3 features and ~88 training rows there is far too
  little data for an MLP to shine; the tree models handle the tiny/low-dimensional setting better.
- **CV and test F1 disagree** (CatBoost/NN have the best CV but not the best test) — the
  hallmark of a fold too small to rank models reliably.
- **Bottom line:** on CFTR, tuning and trying five model families does **not** beat the simple
  baseline; XGBoost on the 3 best features (≈0.95, essentially the floor) is as good as it gets
  here. The real fix is more data, not a fancier model.

## Reproduce

```bash
python3 feature_depth/second_part_for_in_depth_search_models.py --panel CFTR
```
Requires `python3, pandas, numpy, scikit-learn, xgboost, lightgbm, catboost` (+ `matplotlib`
for the plot). Fully reproducible (`random_state=42`). Overwrites the outputs in this folder.
