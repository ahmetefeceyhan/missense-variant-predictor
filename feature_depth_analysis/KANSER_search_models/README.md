# KANSER — Tuned Model Search (XGBoost / LightGBM / CatBoost / NN / DNN)

This folder takes the KANSER panel's **best feature set** and grid-searches **five model
families** to see which predicts `Label` (0 = benign, 1 = pathogenic) best — a step up from the
earlier "nothing fancy" single-XGBoost baseline.

| File | What it is |
|------|------------|
| `KANSER_search_models_results.csv` | One row per model family, **sorted best test F1 → worst**. |
| `KANSER_search_models.png` | Bar chart of test F1 by model family. |
| `README.md` | This document. |

Generated by `feature_depth/second_part_for_in_depth_search_models.py --panel KANSER`.

---

## Setup

- **Feature set:** the panel's best multi-feature configuration — **`xgb_importance` top-10**
  features (recomputed train-only with seed 42).
- **Preprocessing:** `raw` values + **median** impute; categoricals ordinal-encoded. NN/DNN
  additionally get `StandardScaler`.
- **Five model families:**
  - **XGBoost** — grid: `max_depth∈{3,5}`, `learning_rate∈{0.05,0.1}`, `n_estimators=200`, `scale_pos_weight∈{1, neg/pos}`.
  - **LightGBM** — `num_leaves∈{15,31}`, `learning_rate∈{0.05,0.1}`, `n_estimators=200`, `scale_pos_weight∈{1, neg/pos}`.
  - **CatBoost** — `depth∈{4,6}`, `learning_rate∈{0.05,0.1}`, `iterations=200`, `auto_class_weights∈{default, Balanced}`.
  - **NN** (shallow MLP) — `hidden_layer_sizes∈{(32,),(64,)}`, `alpha∈{1e-4,1e-3}`.
  - **DNN** (deep MLP) — `hidden_layer_sizes∈{(64,32),(128,64,32)}`, `alpha∈{1e-4,1e-3}`.
  - *Note:* `MLPClassifier` has no class-weight option, so NN/DNN run unweighted (the imbalance
    axis applies only to the three tree libraries).
- **Evaluation:** grid search via **5-fold StratifiedKFold on the train split only**, scoring
  F1; the refit best estimator is scored on the held-out test fold. Train = 310 (96 benign /
  214 path), test = 78 (24 benign / 54 path). Seed 42 throughout. The majority-class floor
  (always-predict-pathogenic) is **F1 ≈ 0.818** on this test fold.

## Results (test fold, sorted best F1 → worst)

| model | cv F1 | test F1 | test acc | test recall | test precision | best params |
|-------|------:|--------:|---------:|------------:|---------------:|-------------|
| **XGBoost** | 0.918 | **0.9043** | 0.859 | 0.963 | 0.853 | depth 3, lr 0.05, spw 1 |
| CatBoost | 0.919 | 0.9027 | 0.859 | 0.944 | 0.864 | depth 6, lr 0.1 |
| LightGBM | 0.903 | 0.8947 | 0.846 | 0.944 | 0.850 | leaves 15, lr 0.05, spw 0.449 |
| NN | 0.879 | 0.8889 | 0.833 | 0.963 | 0.825 | (32,), α 1e-3 |
| DNN | 0.881 | 0.8545 | 0.795 | 0.870 | 0.839 | (64,32), α 1e-3 |

## What we found

- **XGBoost wins (test F1 0.9043), with CatBoost a near-tie (0.9027).** Both clear the majority
  floor (0.818) by a solid ~0.085, and CatBoost actually has the best precision (0.864) — the
  three tree libraries are the strongest, clustered around 0.89–0.90.
- **Neural nets trail**, and the deeper DNN (0.855) is *worse* than the shallow NN (0.889):
  with only 10 features and ~310 training rows, extra depth just overfits/underperforms.
- **Tuning matched, but did not beat, the basic baseline.** The earlier `xgb_importance` top-10
  with a plain 100-tree XGBoost already scored 0.9043 — grid search lands at the same place, so
  the gain from heavier libraries / tuning is essentially nil on this feature set.
- **Bottom line:** for KANSER, a compact 10-feature XGBoost (or CatBoost) is the recommended
  model; neural nets are not worth it here, and tuning offers no lift over the simple version.

## Reproduce

```bash
python3 feature_depth/second_part_for_in_depth_search_models.py --panel KANSER
```
Requires `python3, pandas, numpy, scikit-learn, xgboost, lightgbm, catboost` (+ `matplotlib`
for the plot). Fully reproducible (`random_state=42`). Overwrites the outputs in this folder.
