# MASTER — Tuned Model Search (XGBoost / LightGBM / CatBoost / NN / DNN)

This folder takes the MASTER panel's **best feature set** and grid-searches **five model
families** to see which predicts `Label` (0 = benign, 1 = pathogenic) best — a step up from the
earlier "nothing fancy" single-XGBoost baseline.

| File | What it is |
|------|------------|
| `MASTER_search_models_results.csv` | One row per model family, **sorted best test F1 → worst**. |
| `MASTER_search_models.png` | Bar chart of test F1 by model family. |
| `README.md` | This document. |

Generated by `feature_depth/second_part_for_in_depth_search_models.py --panel MASTER`.

---

## Setup

- **Feature set:** the panel's best multi-feature configuration — **`xgb_importance` top-200**
  features (recomputed train-only with seed 42).
- **Preprocessing:** `raw` values + **median** impute; categoricals ordinal-encoded. NN/DNN
  additionally get `StandardScaler`.
- **Five model families:**
  - **XGBoost** — grid: `max_depth∈{3,5}`, `learning_rate∈{0.05,0.1}`, `n_estimators=200`, `scale_pos_weight∈{1, neg/pos}`.
  - **LightGBM** — `num_leaves∈{15,31}`, `learning_rate∈{0.05,0.1}`, `n_estimators=200`, `scale_pos_weight∈{1, neg/pos}`.
  - **CatBoost** — `depth∈{4,6}`, `learning_rate∈{0.05,0.1}`, `iterations=200`, `auto_class_weights∈{default, Balanced}`.
  - **NN** (shallow MLP) — `hidden_layer_sizes∈{(32,),(64,)}`, `alpha∈{1e-4,1e-3}`.
  - **DNN** (deep MLP) — `hidden_layer_sizes∈{(64,32),(128,64,32)}`, `alpha∈{1e-4,1e-3}`.
  - *Note:* `MLPClassifier` has no class-weight option, so NN/DNN run unweighted (the imbalance
    axis applies only to the three tree libraries).
- **Evaluation:** grid search via **5-fold StratifiedKFold on the train split only**, scoring
  F1; the refit best estimator is scored on the held-out test fold. Train = 2344 (625 benign /
  1719 path), test = 587 (157 benign / 430 path). Seed 42 throughout. The majority-class floor
  (always-predict-pathogenic) is **F1 ≈ 0.846** on this test fold.

This is the **largest** panel, so its 587-row test fold (157 benign) makes these the most
trustworthy, least-noisy results of any panel.

## What we found

- **CatBoost wins (test F1 0.8921)**, with LightGBM (0.8899) and XGBoost (0.8847) close behind —
  the three gradient-boosting libraries are tightly clustered and all clear the majority floor
  (0.846) with **precision ≈ 0.84–0.85**, the metric that actually separates a useful model from
  the trivial baseline. CV ranking and test ranking agree here (a benefit of the large fold).
- **Neural nets are clearly weaker** (NN 0.862, DNN 0.841) and the **deeper DNN is worse than the
  shallow NN** — even on the largest panel, plain MLPs on 200 ordinal-encoded tabular features
  don't match gradient boosting, and added depth hurts.
- **Tuning roughly matched the basic baseline.** The earlier "nothing fancy" 100-tree XGBoost on
  this same top-200 set scored 0.8935; the tuned CatBoost (0.8921) is essentially tied with it.
  So switching libraries / grid searching did **not** beat the simple baseline here — it confirms
  it, and CatBoost reaches that level with the cleanest precision.
- **Bottom line:** for MASTER, use **CatBoost (or LightGBM) on the `xgb_importance` top-200
  features** — best/near-best F1 with strong precision. Neural nets are not worth it; tuning is a
  wash versus the basic XGBoost, so model *family* and *feature set* matter more than the grid.

## Reproduce

```bash
python3 feature_depth/second_part_for_in_depth_search_models.py --panel MASTER
```
Requires `python3, pandas, numpy, scikit-learn, xgboost, lightgbm, catboost` (+ `matplotlib`
for the plot). This is the slow panel (2344×200 × 5-fold grid search across 5 families —
several minutes). Fully reproducible (`random_state=42`). Overwrites the outputs in this folder.
