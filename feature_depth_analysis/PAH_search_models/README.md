# PAH — Tuned Model Search (XGBoost / LightGBM / CatBoost / NN / DNN)

This folder takes the PAH panel's **best feature set** and grid-searches **five model
families** to see which predicts `Label` (0 = benign, 1 = pathogenic) best — a step up from the
earlier "nothing fancy" single-XGBoost baseline.

| File | What it is |
|------|------------|
| `PAH_search_models_results.csv` | One row per model family, **sorted best test F1 → worst**. |
| `PAH_search_models.png` | Bar chart of test F1 by model family. |
| `README.md` | This document. |

Generated by `feature_depth/second_part_for_in_depth_search_models.py --panel PAH`.

---

## Setup

- **Feature set:** literal report best — a **single feature** `[AL_66]`. (The earlier analysis
  found combining features gave no real benefit on PAH, so the "best" was one feature.)
- **Preprocessing:** `raw` values + **median** impute. NN/DNN additionally get `StandardScaler`.
- **Five model families:**
  - **XGBoost** — grid: `max_depth∈{3,5}`, `learning_rate∈{0.05,0.1}`, `n_estimators=200`, `scale_pos_weight∈{1, neg/pos}`.
  - **LightGBM** — `num_leaves∈{15,31}`, `learning_rate∈{0.05,0.1}`, `n_estimators=200`, `scale_pos_weight∈{1, neg/pos}`.
  - **CatBoost** — `depth∈{4,6}`, `learning_rate∈{0.05,0.1}`, `iterations=200`, `auto_class_weights∈{default, Balanced}`.
  - **NN** (shallow MLP) — `hidden_layer_sizes∈{(32,),(64,)}`, `alpha∈{1e-4,1e-3}`.
  - **DNN** (deep MLP) — `hidden_layer_sizes∈{(64,32),(128,64,32)}`, `alpha∈{1e-4,1e-3}`.
  - *Note:* `MLPClassifier` has no class-weight option, so NN/DNN run unweighted (the imbalance
    axis applies only to the three tree libraries).
- **Evaluation:** grid search via **5-fold StratifiedKFold on the train split only**, scoring
  F1; the refit best estimator is scored on the held-out test fold. Train = 297 (50 benign /
  247 path), test = 75 (13 benign / 62 path). Seed 42 throughout. The majority-class floor
  (always-predict-pathogenic) is **F1 ≈ 0.905** on this test fold.

## What we found

- **All five model families tie at exactly the majority-class floor (F1 0.905, recall 1.0).**
  With a single feature and median imputation, every tuned model — trees and neural nets alike —
  collapses to "predict pathogenic", i.e. it cannot extract a benign decision boundary.
- **Tuning did not help here.** The earlier basic single-feature run scored slightly higher on
  `AL_66` using `raw`+**mean**; with `raw`+**median** preprocessing and CV-tuned (conservative)
  hyperparameters, the models settle at the floor instead. This is a genuine result, not a bug:
  one feature simply does not carry enough signal for any of these models to beat the baseline.
- **Bottom line:** for PAH, neither stronger libraries nor neural nets nor grid search add value
  on top of the single best feature — the panel's discriminative signal is the bottleneck, not
  the model. (Lifting PAH would require multi-feature, missingness-aware modeling, not a heavier
  classifier.)

## Reproduce

```bash
python3 feature_depth/second_part_for_in_depth_search_models.py --panel PAH
```
Requires `python3, pandas, numpy, scikit-learn, xgboost, lightgbm, catboost` (+ `matplotlib`
for the plot). Fully reproducible (`random_state=42`). Overwrites the outputs in this folder.
